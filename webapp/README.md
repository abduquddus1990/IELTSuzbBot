# Web client (Telegram Mini App + browser)

Plain HTML/CSS/JS, no build step. Served by FastAPI at `/webapp/` (the bare domain redirects here).

- `index.html` — shell (exam top bar, question navigation bar, modal, toast)
- `app.js` — screens: home → section intro → Listening / Reading / Writing / Speaking → results
- `styles.css` — light/dark themes, split-screen layout (stacks into tabs below 900 px)
- `audio/*.mp3` — Listening recordings (generated by `tools/generate_listening_audio.py`)
- `manifest.webmanifest`, `sw.js`, `icon.svg` — installable PWA for the browser version

The client never receives answer keys or audio scripts; all scoring happens on the server.
