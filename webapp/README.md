# Telegram Mini App (WebApp) Frontend

This directory houses the Telegram WebApp (Mini App) interface for the **IELTS & CEFR Mock AI** platform:
- **Listening Module**: Synchronized audio player with real-time question navigation.
- **Reading Module**: Split-screen passage reader with highlightable text and question palette.
- **Writing Module**: Countdown timer, live word counter, and anti-cheat telemetry (paste/tab-switch detection).
